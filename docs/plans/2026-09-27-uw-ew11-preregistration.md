# UW E-W11 预注册：洗涤足迹重析（M）+ 确定性地板（N）+ 逐类副作用（O）

日期：2026-09-27。状态：**冻结版（执行前提交）**。依据：作者"继续
补实验"；E-W10 L 臂"存疑"经分析为误判——disp_ratio=‖θw−θ₀‖/‖θR−θ₀‖
对正交小扰动退化为 1+‖δ‖²/2‖Δ‖²，4 位小数即 1.0；正确读数
δ/Δ = sqrt(ratio²−1)。

## Arm M：足迹重析（CPU，复用 ew10L ckpt）
- δ/Δ = ‖θw−θR‖/‖θR−θ₀‖ 逐种子（直接范数，不经球面比）；层群
  份额沿用 group_of；与 P-L1/L2 对判。
- 预测：P-M1：δ/Δ 中位 ∈ [0.5%, 5%]；P-M2：位移质量主在 conv 主干。
- 判定：报告型。

## Arm N：确定性地板（开放问题 3 的经验侧）
- 3 次完全同种子重训（seed_all(46300) 三次独立运行，k=30，40ep 同
  配方）→ 六指标离散 = 硬件/库非确定性抖动地板；换算 γ_floor =
  b_fm/E_fm 与正常跨种子 γ 对照。
- 预测：P-N1：γ_floor < 0.05（抖动远小于跨种子散布——审计方"固定
  种子收窄容差"的残余下限存在但小）；P-N2：同种子重训不相等
  （cudnn 非确定性实证，数字级）。
- 判定：报告型（开放问题 3 的"能否缩 γ"给出两边界）。

## Arm O：逐类副作用（复用 ew10L 洗涤 ckpt + 归档）
- 对 6 个洗涤点 + θ₀ + 6 个 θR：逐类测试精度；读出洗涤相对系综
  中位的最大类级偏差（非 cat 类是否被扰动）。
- 预测：P-O1：非 cat 类最大偏差 ≤ 1pp（效用无损的逐类分辨率证据）。
- 判定：报告型；若 >1pp 如实报（效用声明相应收窄）。

## 预算
M 纯 CPU；N ≈ 3 重训 ~25 min；O ≈ 13 次评估 ~10 min；合计 <1h GPU。
命令 `python -m uw.run_ew11 --gpu 0 [--arm M|N|O] [--smoke]`；输出
`research_outputs/uw/ew11{M,N,O}-<ts>/`。
