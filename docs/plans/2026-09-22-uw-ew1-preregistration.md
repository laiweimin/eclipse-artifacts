# UW E-W1 预注册：统计指标审计下的洗涤容量（线性床，闭式+数值）

日期：2026-09-22。状态：**冻结版（执行前提交）**。依据：作者批准
"立 E-W1 工作包（预注册 + 击杀条件冻结后执行，同 UGS E1 流程）"；上游 =

## 1. 要回答的科学问题

不诚实服务方在**统计指标审计**下能"洗涤"掉多少诚实遗忘更新？——即：
在全部 Tier-A 指标的接受带内，输出模型 θ' 能向 θ₀（删除前模型）回收的
最大行为份额。这是 UW 候选的生死判定（R5：床上容量未知）。

**诚实边界（随结果报告）**：洗涤保留的是被删数据对**非 F 区域**的影响
（null(X_F) 盲分量 + 带宽容忍 row-space 分量；被删记录自身的 F 预测保持
重训水平——定义性边界，见机制卡 §3）。容量是审计几何的函数，不是道德
判断；E-W1 只测几何，E-W2 才做构造与探测存活。

  **扩展池** seed 43801（**2000** 条 cat，同构造公式，声明为 S0-N 冻结
  范围外的新变体）上 k ∈ {100, 300, 1000}——覆盖诚实更新从次容差到远

- 精确参照：θ_R = θ₀ + s_rt（Woodbury，`s0j_ae.linhead` 既定约定，
  S0-N 已数值验证）。
- **审计（S0-N 冻结约定原样）**：六分数 m1_acc/m2_catacc/m3_Floss/
  m4_KS/m5_adv/m6_vsRT（`run_s0n_step3.metrics_at`）；接受带

  holdout、F 内容即可算；m6 需 oracle 参照不计入）。**Tier B（oracle

## 3. 容量定义与方法（冻结）

诚实更新 Δ = θ₀ − θ_R；行为范数 = ‖X_D(·)‖₂（X_D = 全训练特征，
50000×512 满列秩 → 真范数）。**洗涤容量 ρ = 1 − min ‖X_D(θ'−θ₀)‖ /
‖X_D(θ_R−θ₀)‖**，最小化在 θ' 通过所选审计层的接受条件上进行。
ρ=1 = 完美洗涤（θ'=θ₀ 通过审计）；ρ=0 = 不可洗涤。

三个方法（全部报告，容量取最大者）：
1. **c_grid（主方法，精确可行性）**：θ' 限制在 span(Δ) 的行/零分解
   θ' = θ_R + t_row·Δ_row + t_null·Δ_null（Δ_row = Δ 到 row(X_F)
   投影，Δ_null = Δ − Δ_row），(t_row, t_null) 网格步长 0.05（含
   (1,1) 懒惰角点），每点精确计算六指标做可行性判定；最优点后沿
   (0,0)→最优方向黄金分割细化 20 步。
2. **c_refined（全空间精化）**：512 维 w 上投影梯度（目标
   ‖X_D(w−Δ)‖²，带违反回溯投影到最近可行点），5 个初始化
   （零、网格最优、3 随机 seed 46001–46003），≤2000 迭代，只接受
   精确可行点，报告最优可行。
3. **u_qp（上界证书，松弛）**：在 θ_R 处线性化光滑指标（m3/m5/m6，
  解析梯度），min ‖X_D(w−Δ)‖² s.t. |J_i·w| ≤ band_i（m1/m2/m4
  计入松弛 → 解仍为容量上界）；≤6 线性约束的小 QP，KKT/活跃集枚举
  求解；线性化有效性旗标 = 在解处 |预测变化 − 实际变化|/max(实际,
  1e-12) > 0.3 时置旗。

附带几何读出：dim null(X_F) = 512 − rank(X_F)；Δ_row/Δ_null 的参数
与行为范数份额（更新几何）。

## 5. 主 k 与判定（冻结）

- **懒惰转移 k***：主池 43501 上，懒惰角点 (1,1) 在 ≥50% 集合触发
  ≥1 个 Tier-A 报警的最小 k。k ∈ {3,10,30,60} 内无转移 → 查扩展池
  k ∈ {100,300,1000}（同规则）；直至 k=1000 仍无转移 → **退化分支**：
  审计在床尺度上对诚实更新不可分辨 → ρ≡1，判 PASS 但标注"退化区间
  （审计尺度失配）"，E-W2 前须与作者重议带宽——不作为攻击强证据。
- **主 k = k***（转移点）。**PASS 条件**：主 k 上 Tier-A 容量
  （c_grid 与 c_refined 取大、10 集合取中位）≥ **0.10**。
- **KILL 条件**（击杀须上界支撑）：主 k 上该容量 < 0.10 **且**
  u_qp 中位 < 0.10 且线性化有效性通过。二者缺一（容量小但上界不可
  用）→ 不杀，标"未决"交作者/外部审阅（预注册此不确定性）。

## 6. 击杀条款（冻结，不放松）

1. KILL → UW 候选关闭（床上审计几何不可洗涤；诚实报告，换审计层/
   换 k 不自动复活，新预注册另议）；
2. PASS → 提议 E-W2（构造 + UMA 式探测存活），另批；
3. 退化分支 → PASS + 旗标 + 作者重议（不自动进 E-W2）。

## 7. 诚实边界

Tier-A 信息权限声明（m1/m2/m5 用 θ₀+holdout；真实部署审计可能更弱
→ 本判定为**保守下界**——真实审计更弱则攻击更强，不反向）；带宽构造
沿用 S0-N（绝对 τ_h 尺度），k 网格覆盖其过渡；QP 上界依赖线性化局部
有效性（旗标声明）；"容量大"≠"攻击有动机"——经济性属 E-W2/论文层。

**机制结构（k=30）**：懒惰角点由 F 侧指标抓住（m3/m4/m5 9/10 集合，

盲子空间给下界 0.62，带宽补足至 0.70；容量随 k 下降 = null 维随
rank(X_F) 收缩（k=1000 时 null≈0，Tier B oracle 把残余也关到 0.000）。

**读数（诚实边界随行）**：k≤10 次容差区容量平凡 1.0（审计分辨率不
足，非攻击强证据）；k=30–100 为有意义的攻击区（29–70% 可洗涤）；
k≥300 容量 ≤10%（该审计在该床上闭合）。Tier B（oracle vs-retrain）
在 k≤100 几乎不减容量——部署层与 oracle 层的差距本身是发现。容量
是审计几何；伪造经济性与探测类审计存活 = E-W2。
