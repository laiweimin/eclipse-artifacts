## 2. 冻结配置

- **单元扩展（M=6）**：4 个单元 × 3 个新 θ_R 种子（新种子段
  45200 + unit_idx·10 + s）：44700_k300（干涸格，最重要）、

  → 每种子 S0 优化（60 迭代/失速 15）。
- **读出**：每单元 (a) 逐种子 I1；(b) M=1..6 的"≥1 种子 I1 ≥ τ"
  成功率曲线（τ ∈ {0.10, 0.20}）；(c) 单元级 b_fm/E_fm（6 种子版）。
- **定律检验**：全部已测单元（E-W4 3 格 + E-W5 7 格 + 本轮 4 格
  6 种子版 ≈ 14 点）的 Spearman 秩相关（I1* vs b_fm/E_fm）；冻结判
  定：ρ ≥ 0.7 → 定律成立（进入论文作攻击机制节）；ρ ∈ [0.4, 0.7)
  → 部分成立（如实报告散点）；ρ < 0.4 → 定律不成立（E-W5 方差保
  留为诚实边界，攻击主张只靠 Q-RETRY）。
- **判定**：攻击方法主张成立 ⟺ (Q-RETRY) 至少 3/4 单元在 M=6 下
  "≥1 种子 I1 ≥ 0.20" 且（Q-LAW ρ ≥ 0.7 或 M=6 成功率 ≥ 5/6 格
  含新格）；干涸格 M=6 仍 0/6 且定律不成立 → 攻击定位回到作者重议。
- 附带：接受步日志补记完整指标（E-W5 缺口）；每单元 qret 随行。
