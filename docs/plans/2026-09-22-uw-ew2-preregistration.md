## 1. 要回答的问题

E-W1 证明部署层套件（Tier A）在主 k 可洗 70%。E-W2 问两件事：
1. **廉价审计增补能否闭合洗涤**（对抗性框架：攻击者知道审计构成，
   对每个增强套件**重算容量**——弱攻击者假设不采用）；
2. **伪造是否有动机**：洗涤回收的不只是"参数距离"，还有被删数据的
   **效用贡献**吗（提供方动机 = 保住被删数据带来的模型质量）。

## 2. 增强审计套件（全部冻结；带构造同 E-W1：200 个 τ_h 随机方向、
95% 分位、RandomState(62000+si)）

在 Tier A（m1–m5）之上叠加：

| 套件 | 增补指标 | 定义 | 审计者成本 |
|---|---|---|---|
| S1 | m7 全局边际稳定 | \|mean(Xsub @ shift)\|（holdout 连续边际位移——m1 的连续版） | 免费（比 m1 更便宜） |
| S2 | m7 + m8 多向边际 | m8 = max over 20 个 size-100 holdout 子群的 \|mean(Xsub[b] @ shift)\|（子群 seed RandomState(51000+si)） | 20 次检查 |
| S3 | m9 oracle retain 侧 | ‖X_R(shift − s_rt)‖/√\|R\|（X_R = train∖F；**需 θ_R = 全量重训**） | oracle 天花板 |
| S4 | m10 钉定统计残差 | \|‖H_N(θ₀+shift) − b_N‖ − ‖H_N(θ₀+s_rt) − b_N‖\|（H_N = XᵀX/n + λI，b_N = Xᵀy/n；训练时钉定 O(d²)，审计时无需重训） | CRSD-S2 式 |

- **S1/S2 = 裁决相关**（部署可得）；S3/S4 = 锚点报告（S4 预期按
  CRSD r2 归档结论闭合——一致性检验）；S0 = E-W1 Tier A（不重跑，
  引用 0.702）。
- 容量方法同 E-W1：S1/S2 用网格+精化（预算 2000 跨 5 起点）；S3/S4
  仅网格（锚点只需下界证据 + 预期 ≈0）。

## 3. 伪造动机量化（冻结）

- 效用 U(θ) = mean(y_bin_te ⊙ (Xte θ))（全测试集带符号边际）；
  **质量回收份额** = 1 − (U(θ₀)−U(θ_wash))/(U(θ₀)−U(θ_R))，θ_wash =
  S1 套件下最优洗涤（对抗最强裁决相关套件）。
- 附带读出：cat 测试边际回收。若 |U(θ₀)−U(θ_R)| < 1e-12（删除不动
  效用）→ 回收无定义 → 置旗"无效用风险"。
- 诚实边界：床内重训本身便宜（512×512 求解），**算力经济性在床内
  空洞**——动机口径 = 效用保留，算力动机留给 E-W3 深尺度。

## 5. 预测登记（执行前冻结，区分预测与事后）

- P1：S1 大概率**无效**（全局均值边际太粗——诚实更新的全局边际位移

## 6. 判定（冻结）

在主 k=30（池 43501，10 集中位）：
- **K1（廉价闭合击杀）**：cap(S1) < 0.10 **且** cap(S2) < 0.10 →
  两个免费/廉价增补都闭合 → **候选作为攻击关闭**（发现翻转为"存在
  廉价审计修复"；E-W3 不启动；诚实报告）；
- **K2（动机击杀）**：质量回收中位 < 0.25（或"无用效风险"旗）→
  伪造不具实质 → 关闭；

  → 攻击成立 + 防御缺口量化 → 提议 E-W3（深尺度试点）；
- 其余形态 → **UNDECIDED** 交作者/外部审阅。
- S3/S4 结果不参与判定（锚点），但若 S4 **未**闭合（容量 ≥ 0.10）
  → 与 CRSD r2 归档结论矛盾 → 强制 UNDECIDED + 复查（预注册此规则）。

## 7. 诚实边界

对抗性框架声明（攻击者知道套件构成 = 强攻击者）；床限定；S2 的子群
构造是审计设计之一（更强审计设计空间未穷尽——结果读作"存在/不存在

**预测记分（§5）**：P1 ✓（S1 无效）；P2 ✗（S2 同样无效——多向子群

**判定：UNDECIDED（按冻结 §6 规则触发）+ 复查记录**：
- 触发原因：cap(S4) = 0.637 ≥ 0.10，规则称"与 CRSD r2 归档矛盾"。
- **复查结论：规则前提为分析错误，非归档矛盾**。CRSD r2 的 S2 残差
  检验是**免容差、确定性**的，且其钉定对象是**训练期即可钉定的命名
  参照**（D_ref 的充分统计量）——零误报来自精确代数。洗涤问题的参照
  是 θ_R（删除处理时才产生），审计者要么重算（= oracle 成本，且任何
  **带容差**的实现同受 τ_h 分辨率限制——S3 实测即证），要么只持带容
  差统计量。床为确定性，免容差 oracle 检查平凡闭合一切（容量 0），但
  它等价于审计者亲自重做遗忘。**S4 实测 0.637 因此是对 CRSD 归档结论
  适用边界的正确刻画，不是矛盾。**
- 除 S4 规则外，其余判据全部满足 PASS 分支（qret ≥ 0.25 ✓；
  cap(S1)、cap(S2) ≥ 0.10 ✓）。

**核心科学结论（跨 E-W1/E-W2 稳定）**：k=30（0.06% 删除）处，从部署
层到 oracle 层的一切**带容差**审计都留下 ≥60% 洗涤容量——约束不是指
标家族而是审计的绝对噪声底 τ_h；唯一免容差闭合需要审计者以 oracle 成
本复现遗忘。廉价审计增补（连续边际/多向子群）在任何 k 都无效。
