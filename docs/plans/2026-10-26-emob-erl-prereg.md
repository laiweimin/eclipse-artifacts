# 预注册卡：E-MOB（MobileNetV2 编码复现）+ E-RL（relearning 存留探针）

日期：2026-10-26。依据：实验方法学审查（本轮）最小修改集，作者批准。
对象论文：`Latex/UW-Combined`（acceptance–readout gap 主线）。

## E-MOB：MobileNetV2 上复现编码 + z-readout

**目的**：检验 §V 编码—读出差距是否跨架构成立（审查缺陷 1 的实验侧修复）。

**资产复用（零新训练）**：`ez1-mob-20261002T080210` 的 30 个诚实 ft 模型
（z1–z5 × 6 种子，六指标 mm json 齐）+ `make_context(CELLS['mob'])`。
删除请求身份与 ResNet 线完全一致（cls=3、build_pool、f_deep、同种子）。

**审计实例（A6-mob，全新构造并披露与 ez1 自算 q 的差异）**：
fit = z1（c/sig 中位数/MAD）；cal = z2+z3（12 模型，conformal q̂α）；
starts = z4+z5 中在新规则下通过 α=0.20 的前 6 个。

**编码**：ce_gen 冻结协议原样（Eq. J_CE、RandomState(53600)、60 迭代、
接受条件 s6 ≤ q̂0.20）；6 起点。集合构造种子与 run_lfpr 逐字相同
（cons 52801 / fresh 52501 / aux 53304 / ret 52701）。

**读出**：label-blind AUC（neggrad 通道，2000 次目标记录重抽样 95% 区间）+
z-neggrad TPR@5%（aux 冻结阈值，实测 FPR 并报；z 校准参照 = z1 六模型）。

**预冻结门**：
- G0（审计健全性）：z5 系综在新规则 α=0.20 下接受 ≥4/6；不过则停并报告。
- G1（编码有效）：≥4/6 起点重抽样区间排除 0。
- G2（读出差距复现）：过审终态中 ≥4/6 的 z-TPR@5% 配对增量为正，
  且最强过审 TPR ≥ 0.20。
- 判定：G1∧G2 = REPLICATED（论文按复现表述）；仅其一 = PARTIAL（如实分层
  报告）；皆否 = NOT-PORTABLE（诚实负结果，论文主张收窄到 ResNet-18 并
  报告该负结果）。

**预算**：~1.5h GPU（编码 6 起点 ≈45min + 评估）。输出
`research_outputs/uw/emob-<ts>/`。

## E-RL：良性下游使用下的信号存留（relearning 探针）

**目的**：过审编码终态经保留集微调（部署方良性适应的代理）后，
逐记录信号是否存留（审查缺陷 2 的实验侧修复）。

**对象**：11 个过审终态（6 CE = lfpr ckpt 再生版；5 过审 GR = gate-g1b）
+ 6 个 base 起点（配对控制，隔离 ft 自身对 TPR 的移动）。

**干预**：`fit_full(keep, seed, epochs, init=模型)`，lr 0.01；
臂 = ft1×2 种子 + ft3×1 种子。

**读出（ft 后）**：s6（审计状态，描述性）、m1、z-neggrad TPR@5%、
label-blind AUC。

**预冻结门**：存留比 R = (TPR_fin_ft − TPR_base_ft)/(TPR_fin − TPR_base)
（分母为正的终态上计算）。中位 R(ft1) ≥ 0.5 = 存留；中位 R(ft1) ≤ 0 =
被冲刷；中间 = 部分存留。三种结果全部如实入档，不做有利解释。

**预算**：~1.5h GPU（~85 epoch 单位 + 评估）。输出
`research_outputs/uw/erl-<ts>/`。

## 运行前修订（2026-10-26，冒烟后、正式运行前）

**G0 修订**：冒烟显示 G0 以 n=6 检验边际覆盖属欠功效设计（α=0.20 下

（有功效的覆盖估计）。z5 的 3/6 如实入档。正式运行据此放行；
此修订为运行前显式登记，非事后改门。

## E-C100：CIFAR-100 数据集轴复现（运行前追加登记）

**目的**：编码+z-readout 的数据集轴（审查缺陷 1 的最后一项）。
资产复用 `ez2-c100-20261002T084229`（30 诚实 ft 模型，spec=CELLS['c100']，
ResNet-18/cls=0/full_class）。审计实例同 E-MOB 模式（fit=z1、cal=z2+z3、
起点=z4/z5 过审前 6）。

**协议适配（披露）**：CIFAR-100 每类训练侧仅 500 条（池−F=470）、测试侧
100 条，同类不重叠集合放不下 CIFAR-10 尺寸（Nc300+fresh200+aux100）。
缩尺为同类训练侧：Nc=200、fresh(N_eval)=100、aux=100、ret=30（种子常量
不变；FPR 分辨率降为 0.01）。其余（ce_gen 冻结协议、z 校准、门 G1/G2）
与 E-MOB 逐字相同。**G0'（健全性）**：fit 身份校验通过 + ez2 自身 24
模型 α=0.2 接受率 0.92。

**预算**：~30min GPU（优先 GPU 0，>70℃ 才用 GPU 1）。输出
`research_outputs/uw/ec100-<ts>/`。

## E-SEQ：同模型连续删除请求探针（运行前登记）

**问题三分**：(G1) 请求-1 的编码终态 θ₁ 未处理直接面对请求-2 审计
（F₂ = 类池中与 F₁ 不相交的 30 条，种子 54301）——陈旧模型是否被拒
（base 同测作零假设：诚实 θ₁ 同样含 F₂，也应被拒）；(G2) θ₁ 经诚实
请求-2 处理（D∖(F₁∪F₂) 上 1 epoch ft，种子 905/906）后 F₁ 信号存留
（配对 base 控制，同 E-RL 口径）；(G3) 第二次编码（诚实处理后起点，
ce_gen 冻结协议，F₂ 目标）能否过审并使 F₂ 可读，F₁ 残留描述性报告。

**请求-2 审计实例**：18 个 F₁-族诚实模型（ew9F 6 + ex3 e3 6 + e4 6）
各在 keep₁∪₂ 上 ft 1 epoch（新种子 4740x）；fit=ew9F′、cal=e3′
（n=6，conformal ⌈7×0.8⌉=6 阶，披露）、起点检查=e4′ 过审。
F₂ 的上下文经模块级 f_deep 替换构造（F₁ 上下文保留用于 F₁ 读出）。

**门（预冻结）**：G1 = base 与两 θ₁ 全部被拒（任一接受 = 审计-2 漏检
陈旧模型，负结果如实报）；G2 = 两终态中位 R < 0.5 → 冲刷，≥0.5 →
存留；G3 = 过审 ∧ F₂ z-TPR 增量 > 0（复合成立），否则不复合。

**预算**：~35min GPU（21 epoch + 评估）。输出 `eseq-<ts>/`。

## 诚实边界

- E-MOB 是单数据集（CIFAR-10）单类（cat）单删除请求的架构轴复现；
  数据集轴（CIFAR-100）与类轴不在本轮。
- E-RL 的 ft 是部署适应的代理而非对抗性 relearning-on-forget；
  后者如需另立卡。
- 两轮结果无论方向如何都更新论文（复现→扩主张；负→收窄并报告）。

## E-SP：CIFAR-100 边界的池几何判别（运行前登记，7→8 路线第二阶段第 3 项）

**判别问题**：E-C100 的校准读出增益缺失（≤+0.07）由何者解释——
(a) 池几何（500 条类池 → 删除占比 6% + f_deep 选点更尖锐 + 集合
缩尺 Nc200/eval100）或 (b) CIFAR-100 数据集真实依赖？

**设计**：CIFAR-10 cat 类，build_pool 结果以种子 54501 截到 500 条
（其余协议与主实验同细胞）；F = f_deep(池₅₀₀, 30)；诚实族 = θ₀
（ew3）在 keep = D∖F 上 1-epoch ft × 18（种子 47501–47518，自建）；
A6-SP：fit=前 6（median/MAD）、cal=中 6（conformal α=0.20）、
起点=后 6 中过审者。集合（训练侧同类）：Nc=200/fresh=100/aux=100/
ret=30，种子 52801/52501/53304/52701——逐字匹配 E-C100 适配。
编码 = ce_gen 冻结协议。读出 = AUC(ng) 重抽样 CI + z-TPR@5%
（z 校准 = SP fit 六模型）。

**门（预冻结，与 E-C100 同门）**：G1 = ≥4/6 AUC CI 排除零；
G2 = ≥4/6 过审终态 z-TPR 增量正 ∧ 最强 ≥ 0.20。
**判别逻辑**：两门 FAIL（复现 E-C100 形态）→ **几何解释成立**
（边界 = 池几何/占比/缩尺，论文"boundary, explained"）；两门 PASS
→ **数据集真实依赖**（CIFAR-10 小池仍复现，边界归属 CIFAR-100
本身，如实分层）；分裂结果如实报告。

**预算**：18×1ep ft（~12min）+ 6 起点编码（~40min）+ 评估 ≈ 1h
GPU（优先 GPU 0，>70℃ 用 1）。输出 `research_outputs/uw/esp-<ts>/`。
