# 预注册卡 E2：多类正面域复制（修复"单类"边界）— 2026-11-03

来源：作者 2026-11-03 指示"彻底修复单数据集/单类正面域窄"。主正面域现为 CIFAR-10 cat（类 3）；本实验在 **3 个新类**上完整复制"审计 + 编码 + 读出"管线。**各类两态结果均入稿**；NOT-REPLICATED 类如实报告为类级边界（与 cat 的正结果并列，不抹除）。

## 设计（每类独立实例）

- **类**：dog（5）、airplane（0）、frog（6）——与 cat（3）语义/特征距离各异。
- **θ₀**：同 ew3 theta0（全类训练，跨类合法）；pool = build_pool(该类)；F = f_deep(pool_cls, 30)（θ₀ 边际选点，类内确定性）。
- **诚实族**：24 个 θ₀ → keep_cls 1-epoch ft（Table IV ft 配方），种子 dog 47651–74 / airplane 47681–704 / frog 47711–34（与全部历史种子及 E1 不交）。
- **审计 A6-cls**：fit = 前 6（median/MAD）；cal = 中 12（conformal α=0.20，与主实验 n_cal=12 一致）；起点 = 后 6。
- **集合**：该类测试侧 cons 300 / fresh 200 / aux 100（种子模式同主实验：52801/52501/53304）。
- **编码**：ce_gen 冻结协议 ×6 起点（接受检查 = 该类 s6 ≤ 该类 q̂）。
- **读数**：每起点过审、AUC(ng) base→final + 95% CI（2000 重抽样）；次要 = z-AUC（对该类 fit-6 参照）；类级诚实过审率。

## 门（看结果前冻结，逐类）

- **CLASS-REPLICATED**：≥2/6 起点产出"过审 ∧ CI 正增益"；
- **CLASS-PARTIAL**：恰 1/6；
- **CLASS-NOT-REPLICATED**：0/6。
- 总账口径：cat + 3 新类中 REPLICATED 的类数（"X/4 类复制"），全部入稿不改旧阈值。

## 运行披露（5h 门）

- 命令：`python -m uw.run_e2mcls --gpu 1 --outdir research_outputs/uw/e2mcls-<ts>`
- 每类 ≈ 24 ft × 1.5min + 6 编码 × 2.5min ≈ **55min**；3 类 ≈ **2.8h（< 5h 门，GPU 1）**；与 E1 并行不冲突（不同 GPU/目录）。
