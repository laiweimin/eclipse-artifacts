## 臂 A：λ 对比权重扫描

- J_CE = E_F ℓ − λ·E_Nc ℓ；λ ∈ {0.25, 0.5（冻结参照）, 1.0, 2.0}；起点 = e3-s1/e3-s3/e4-s0（3 个已知信号起点）；其余协议逐字（60 迭代、Nc=300）。
- **门（冻结）**：λ-FLAT = 各 λ 的均值增益相对差 < 2×（0.5 非关键）；λ-SENSITIVE = 存在 >2× 差异（报告最优 λ 与 0.5 的关系）。

## 臂 B：Nc 池规模扫描

- Nc ∈ {30, 100, 300（冻结参照）, 1000}；同 3 起点；λ=0.5、60 迭代。构造集从 cons 300 池内按种子重抽（Nc=1000 需扩池至类测试侧全集补足）。
- **门（冻结）**：NC-ROBUST = 某 Nc<300 的均值增益 ≥ 300 的 90%；NC-COLLAPSE = Nc≤100 增益 < 300 的一半（复现协议要求段的 30-塌缩并定位阈值）。

## 臂 C：迭代预算扫描

- **门（冻结）**：ITER-SATURATED = n=30 与 60 均值差 < 0.03；ITER-HUNGRY = 120 显著高于 60（CI 分离）。
