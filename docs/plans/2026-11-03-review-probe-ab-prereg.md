# 预注册卡：审稿裁决 15 两探针（a 收紧阈值编码 / b 独立校准编码）— 2026-11-03

来源：`docs/decisions/2026-11-02-four-model-review-consolidation.md` 裁决 15（作者 2026-11-03 批准并行执行）。单单元可行性证据，非矩阵；两态结果均入稿，不改旧阈值、不触碰已闭合产物。

## 探针 a：收紧阈值下的编码重优化（TIGHT）

**动机**：B2 裁决 9a 零训练重算显示 0.99q̂ 以零诚实代价拒全部 11 个边界钉扎终态；正文现留 "whether an encoder can re-optimiz under a tightened threshold is untested"。DeepSeek M3 称阈值稳健性是该主张最重要的缺失消融。

**设计**：ce_gen 冻结协议（run_lfpr 逐字），仅把接受检查阈值换为 `s6 ≤ 0.99·q̂ = 5.193` 与 `s6 ≤ 0.95·q̂ = 4.983` 两臂；起点 = e3-s1 / e4-s0 / e4-s1（3 个强 CE 起点，ex3 诚实 ft）；60 迭代；输出 root `probe-t-<ts>`。

**读数**：每臂每起点——可行性（有无被接受步）、终态 s6（真审计计分）、AUC(ng) 增益与 95% 重抽样 CI（rank_ci，2000 次，成员重抽样配对，同 Table VIII 口径）。

**门（看结果前冻结）**：
- TIGHT-FOLLOWED：任一臂 ≥1 起点产出"终态过该臂阈值 ∧ CI 下界>0"——攻击跟进收紧阈值，"1% 免费防御"降级为军备竞赛再移动；
- TIGHT-BLOCKS：两臂共 6 次编码全部无可行终态或全无 CI 正增益——收紧阈值（在其实际诚实代价下）为该实例的有效廉价防御；
- MIXED：其余。

## 探针 b：独立校准下的编码（IND-CAL）

**动机**：全稿最大已披露 caveat = "provider-known bands"（§III-D、贡献 (2)、Limitations）。GLM 结构缺口 1 / DeepSeek M4。测量化：提供方不知审计方校准抽样时攻击是否仍可行。

**设计**：
1. 提供方自有系综：12 个全新诚实 ft（θ₀ → keep 1 epoch，run_a9z3.ft_arm 逐字配方），种子 45501–45512（与全部历史种子不交：ex3 468xx / ew9F 459xx / a9z3 453xx-454xx）。
2. 提供方估计审计（同规则、自有抽样）：ĉ/σ̂ ← 前 6 个（fit-est）的六指标均值/标准差；q̂_est ← 后 6 个（cal-est）s_est 的 split-conformal α=0.20 分位（与审计同构造）。
3. 编码：ce_gen 冻结协议，接受检查用 s_est ≤ q̂_est；起点 = e3-s1 / e3-s3 / e4-s0；60 迭代。
4. 提交真审计：终态按真审计（ew9F 中心 + q̂=5.245）计分。

**读数**：q̂_est 与真 q̂ 的偏差；cal-est 模型的真审计分数分布（估计带 vs 真带）；每起点终态的真 s6、真审计通过、AUC(ng) 增益 CI。

**门（看结果前冻结）**：
- IND-CAL-SURVIVES：≥1/3 起点终态过真审计 ∧ CI 下界>0——最大 caveat 被实测消除，威胁模型实质放宽；
- REQUIRES-KNOWN-CAL：0/3 过真审计——caveat 从假设变为实测边界（攻击当前需已知带），主张收窄但更硬；
- MIXED：过审但无信号，或反之。
