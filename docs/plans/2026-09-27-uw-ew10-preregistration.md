# UW E-W10 预注册：尺度端点 k=2000 + 第二近似算子（NegGrad）+ 洗涤足迹

日期：2026-09-27。状态：**冻结版（执行前提交）**。依据：作者"继续补实验"。

## 1. Arm I：k=2000 尺度端点（全池删除 = cat 类 40% / 训练集 4%）

- 单元：CIFAR-10，θ₀=44500，F = f_deep(pool, 2000)（全池），重训
  seed_all(46100+s)，s∈{1..6}（40ep 同配方）；审计/优化同旧（Tier-A
  自含系综带 + S0）。
- 读出：γ、I1*、泄露率；主表曲线端点。
- 预测：P-I1：γ < 0.10（删除效应远超系综散布）→ I1* < 0.10 或 0
  （定律预测的关闭端点——零端点本身是信息，非坏结果）。
- 判定：报告型（曲线端点）；若 I1* ≥ 0.10 则定律带需外推修正（如实）。

## 2. Arm J：第二近似算子参照——NegGrad 上升族

- 动机：E-W9 仅 ft 算子；NegGrad（对 F 损失做梯度**上升** T 步，
  \cite{goel2022adversarial} 语境中的上升族算子）是随机性算子，
  种子驱动 → 真系综。
- 算子定义（冻结）：从 θ₀ 出发，对 F 上的 CE 损失做 T=300 步梯度
  上升（lr 0.01，seed_all(46200+s)；s∈{1..6}）。
  [勘误 2026-09-27 全量前：冒烟显示全 F 单批近乎确定性（γ=0.0001
  → 带塌缩伪象）；改为 **size-100 有放回小批采样**（种子生成器控
  制——真实部署的随机算子形态，系综散布有来源）。判定逻辑不变。]
- 审计/洗涤：Tier-A 心/带 = NegGrad 系综自含带；γ_NG、I1、S0 洗涤；
  k=30。
- 预测：P-J1：I1* ≥ 0.10（算子散布宽 → 洗涤存活）；P-J2：γ_NG 与
  γ_ft 同量级（0.2–0.5）。
- 判定：k=30 任一种子 I1 ≥ 0.10 → 第二算子参照下成立；全零 → 如实
  报告（两算子边界不同）。

## 3. Arm L：洗涤足迹（攻击代价维度）

- 重跑 t44500_k30 六种子 S0 并**落盘洗涤点**；读出：
  (a) 参数位移比 ‖θ_w−θ_R‖/‖θ₀−θ_R‖（分布）；
  (b) 位移的层群分布（BN 统计 / BN 仿射 / conv 组 / fc——group_of
  沿用 E-W3b 定义）；
  (c) 与回滚足迹对照（回滚 c*=0 vs 洗涤的实际位移量级）。
- 预测：P-L1：位移比中位 ∈ [0.02, 0.15]（洗涤是小参数改动——
  "细小扰动跨过审计"的直观定量化）；P-L2：位移质量集中于 conv 主干
  （fc/bn 不足以载影响——与贪婪回滚 fc.bias 独存互证）。
- 判定：报告型。

## 4. 预算与执行

- 命令 `python -m uw.run_ew10 --gpu 0 [--arm I|J|L] [--smoke]`；
  输出 `research_outputs/uw/ew10{I|J|L}-<ts>/`；~2.5–3h GPU（I ≈
  6 重训 45 min + 洗涤 30 min；J ≈ 6×3 min 算子 + 洗涤 30 min；
  L ≈ 30 min）；启动前 nvidia-smi ≤65℃。
- 失败策略沿旧（逐单元落盘续跑）。

## 5. 诚实边界

k=2000 为全池删除（无均匀对照历史值）；NegGrad 为上升族代表（SSD
确定性算子的带语义不同——点参照情形留讨论节，如实声明）；足迹为
参数空间度量（黑盒审计者不可见，作为攻击规模刻画非检测手段）；
单 θ₀/单 k 每臂。
