## 4. 深尺度指标实例化（冻结）

| 指标 | 定义（真实 logits） | 层 |
|---|---|---|
| m1 | 全测试集总体精度 | A |
| m2 | cat 类测试精度 | A |
| m3 | F 上平均 CE 损失 | A |
| m4 | KS(F 逐样本损失 ‖ 冻结保留子样本 3000 逐样本损失)；子样本 RandomState(52000) 于非 F 训练记录 | A |
| m5 | 对手 AUC：标准化特征 [CE, 正确类边际] 上的手写逻辑回归（200 全批步 lr=0.1）区分 F vs 保留子样本，AUC = Mann-Whitney U | A |
| m6 | oracle：\|Fmargin(θ′) − median_s Fmargin(θ_R^{k,s})\| 越带判定 | B |

Fmargin = F 上正确类边际 z[y] − max_{j≠y} z[j] 的均值（影响量 I1 的
载体；m6 用同一量）。**带宽**：B_m = max_s |m(θ⁰_s) − median
m(θ⁰_·)|（6 个 k=0 诚实重训；max = 校准集 0% FPR 的最宽可辩护带，
对洗涤最有利——在此带下 PASS 是保守方向）。**稳健读数**：另记录
半带 B_m/2（激进审计）下的通过/c*，双口径并报。

**接受判定**：θ′ 通过 k-审计 ⟺ 对全部 Tier-A 指标
|m(θ′) − median_s m(θ_R^{k,s})| ≤ B_m（带心 = 该 k 的 3 个 θ_R 中位）。

**材料性门（防平凡）**：删除效应 E_k = |Fmargin(θ₀) − median
Fmargin(θ_R^k)| ≥ 3·B_Fmargin 才算"删除在该 k 有可测效应"；I1 =
(Fmargin(θ′_{c*}) − Fmargin(θ_R))/(Fmargin(θ₀) − Fmargin(θ_R))，
分母 < 3B 的 k 不进入 PASS/KILL 判定（其容量读数标注"平凡区"）。
效用代价随行：θ′_{c*} 的 m1 vs θ_R 的 m1（损害与代价同报，项目规则）。

## 6. 判定（冻结）

- **材料性门**：若所有 k 均平凡（E_k < 3B）→ **UNDECIDED**（本轮
  k 网格上删除不可测；上探 k 或换定向 F 的重设计交作者，不作关闭）。
- **KILL**：存在材料 k，但全部材料 k 上 Tier-A 前沿 I1 < 0.20 →
  深尺度审计闭合洗涤；候选按深尺度关闭（线性床结论保留为床内事实），
  反向发现（诚实重训噪声带下审计非真空、floor 不成立处）如实报告
  并提议是否值得作为审计正面结果整理。
- **PASS**：存在材料 k 且其 Tier-A I1 ≥ 0.20 → 深尺度洗涤容量成立；
  k=30 floor 读数（无论方向）独立报告；提议 E-W4（多 θ₀/算子/定向 F
  /防御侧）或论文骨架评估。
- **UNDECIDED**（其余）：L→R 单调性不符（几何迁移失败，P2 式）/
  Tier-B 反常闭合 / 材料性门未过 → 交作者/外部审阅。
