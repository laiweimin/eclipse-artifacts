# UW E-W9 预注册：近似算子参照（补充实验）+ 指标消融 + 异质性分析

日期：2026-09-27。状态：**冻结版（执行前提交）**。依据：作者指示
"补充实验、异质、消融"（审前标准件补强）。

## 1. Arm F：近似算子参照（补充实验，最关键假设检验）

论文现有威胁模型的诚实参照族 = 精确重训；真实部署审计的参照多为
**近似遗忘算子**（其系综散布更大）。问题：当审计的参照族与带都来自
近似算子时，带内洗涤是否存在？

- 单元：CIFAR-10，θ₀=44500（ew3 ckpt），k ∈ {30, 1000}，
  F = f_deep(pool, k)。
- 诚实算子族：**θ_ft^(s) = 从 θ₀ 出发 1-epoch SGD ft 于 D∖F**
  （lr 0.01/0.9/5e-4，batch 100——S0-H/ETIE 既定算子），种子
  seed_all(45900+10·ki+s)，s∈{1..6}。
- 审计：Tier-A 心/带 = ft 系综自含带；γ_ft 与 I1 按同公式
  （fm 参照 = ft 系综中位、fm_0 不变）。
- 洗涤：每 ft 种子 S0 优化（60/15，对照同旧）。
- **判定（冻结）**：k=30 任一种子 I1 ≥ 0.10 → **近似算子审计下
  洗涤成立**（攻击面扩至真实部署参照；预期方向：算子散布更大 →
  带更宽 → 容量更高——如实报告）；全部 < 0.10 → 诚实边界（近似
  算子审计闭合；同样如实）。k=1000 同读出。
- 预测登记：P-F1：k=30 I1*_ft ≥ 0.20（宽带预期）；P-F2：γ_ft >
  γ_retrain 同单元。

## 2. Arm G：指标消融（audit suite ablation）

- 单元：ew6 t44500_k30 六种子 ckpt 复用。
- 变体：Tier-A 逐指标剔除（−m1,…,−m5 共 5 变体），每变体 6 种子
  S0 重优化；读数 ΔI1* 相对全套（0.248）。
- 判定：报告型——ΔI1* 排序即各指标的约束贡献；预期 m5/m3 剔除
  放大最甚（绑定点即它们）。
- 预测登记：P-G1：剔 m5 或 m3 的 ΔI1* 最大；P-G2：任一单剔不使
  I1* 超 0.40。

## 3. Arm H：异质性分析

- **H1 方差解释**：18 格上 I1* 对 γ 的秩 R²（=ρ²）+ 残差最大的
  正负两格识别（CPU，archived）。
- **H2 带源消融（3 vs 6 种子）**：四单元同测（ew5 3 种子 vs ew6
  6 种子）：γ、I1*、泄露率对照表——正式化"干涸格翻案"为消融
  （CPU，archived）。
- **H3 泄露记录身份**：44102 单种子重跑 S0 并**落盘洗涤点**；
  逐记录边际恢复（wash vs θ₀ 差）与 θ₀ 边际排名的相关——
  高记忆（高边际）记录是否优先被保留？（~20 min GPU）。
- 预测登记：P-H1：秩 R² ≥ 0.5；P-H3：正相关（高边际优先保留）。

## 4. 预算与执行

~3 h GPU（Arm F ~1h；Arm G ~1.5h；H3 ~0.3h；H1/H2 CPU）；
命令 `python -m uw.run_ew9 --gpu 0 [--arm F|G|H] [--smoke]`；
输出 `research_outputs/uw/ew9{F|G|H}-<ts>/`；逐单元落盘可续跑；
启动前 nvidia-smi ≤65℃。失败策略沿旧。

## 5. 诚实边界

ft 算子为单一近似族（SSD/SCRUB 未入本轮——线性床 ssd_simple 不
可直接迁移，如实声明）；Arm F 的 I1 分母用 ft 参照（与重训族数值
不可直接比，只比"是否过物质线"）；H3 单种子单点（illustrative）；
消融限于指标维（步长/迭代维不值得消融——饱和即停已证）。
