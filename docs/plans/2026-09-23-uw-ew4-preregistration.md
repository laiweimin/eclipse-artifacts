## 2. 冻结配置

- **审计**：Tier-A 五指标；带 = **自含诚实系综带**（该 k 的 3 个
  θ_R 对带心最大偏离；E-W3b 勘误 2 的构造）；带心 = 3 种子中位。
  bands/centers 由 ew3 归档 rt jsons 直接重算（逐 k）。
- **优化器**：E-W3b 终版（lr 初值 1e-3、回溯 12 次、上限 3e-3、
  接受阈值 1e-7、迭代上限 **60**、失速停 **15**、目标 = F 边际、
  接受 iff 可行且边际改进）。**新增：接受步记录完整指标**（含
  m3/m4/m5 对带相对偏差——E-W3b 的机制记录缺口）。
- **起点（每 (k,seed) 4 个）**：S0 = θ_R^s；S1/S2 = 向另外两个种子
  混合 t=0.3（不可行则 t=0.15，再不可行弃置并记录）；S3 = 随机方向
  RandomState(45500+100·ki+seed_idx·10+3)，尺度阶梯
  r ∈ {0.1,0.05,0.02,0.01}·‖θ_R^s−θ₀‖ 直至可行，全不可行弃置。
- **对照（每 (k,seed)）**：5 步无约束自适应上升，F 边际增益 ≥ 0.5
  方为优化器可用（否则该 (k,seed) UNDECIDED，不得计入闭合）。
- **动机读出**：qret = 1 − (U(θ₀)−U(wash*))/(U(θ₀)−U(θ_R))，
  U = mean 测试正确类边际（util_margin）；cat 边际恢复份额同式；
  分母 < 1e-3 → 置旗"效用分母平凡"。
- 矩阵：3 k × 3 seeds × 4 起点 = 36 个优化运行 + 9 个对照。

## 3. 预测登记（执行前冻结）

- P1：I1*(k) 单调下降；I1*(30) ∈ [0.25, 0.40]（多起点高于 0.248）；
  I1*(300) ∈ [0.05, 0.20]；I1*(1000) ∈ [0, 0.15]（不确定区间如实
  登记，不下注点值）。
- P2：多起点修复 44103 型起点（至少 1 个混合起点产生接受步）。
- P3：k=1000 处若 I1* ≥ 0.10 则 qret 同向但幅度更低；k=30 qret
  分母平凡置旗。
- P4（机制）：接受点近绑定指标为 F 侧（m3/m4/m5 相对偏差 ≥ 0.8）
  而非 m1/m2。

## 4. 判定（冻结）

- **PASS（攻击线继续 → 方法论文评估）**：I1*(1000) ≥ 0.10 **或**
  I1*(30) 与 I1*(300) 均 ≥ 0.20——漏洞在有效删除规模存活。
- **KILL（漏洞为小 k 现象，攻击线收缩回收口短文）**：I1*(300) <
  0.10 **且** I1*(1000) < 0.10——三件套改写为"回滚闭合 + 仅小 k
  优化漏洞 + 校准律"，UW 攻击线按此归档。
- **UNDECIDED**：任一 (k,seed) 对照失败且影响该 k 的最优值判定 /
  可行起点弃置率 > 50% / 其它异常形态 → 交作者。
- qret 只报告不进门（动机口径 = 影响保留本身即损害；效用同报是
  代价纪律非判定条件）。

## 5. 诚实边界

单 θ₀/单架构/单数据集/均匀 cat 池 F（非最坏构造）；局部梯度 +
有限起点（容量为下界证据；PASS 方向保守，KILL 方向受"更强优化器
可能找到更多"的残余不确定性约束——如实声明）；系综带 3 种子小
样本；Tier-A 审计（Tier-B 在 E-W3 已同闭）；优化点模型不落盘
（接受步指标全记录；重算受 cudnn 非确定性影响）。
