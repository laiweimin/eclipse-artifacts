# UW E-W3b 迷你预注册：优化洗涤补漏（E-W3 KILL 的构造族漏洞检查）

日期：2026-09-23。状态：**冻结版（执行前提交）**。依据：作者批准
"先花半天做 (a) … + (b) ~2h GPU 优化洗涤补漏"。压力测试指认的漏洞：
E-W3 只测了**回滚形**洗涤（均匀插值/ft+回滚），未测带约束优化与非
均匀回滚——床上最优洗涤正是非均匀的（row/null 独立取值）。本实验
回答：E-W3 审计接受域内是否存在保留实质 F 影响的模型。

## 1. 冻结配置

- 输入（全部复用 `ew3-20260925T113900/`，无新训练）：θ₀（44500）、
  k=30 的 3 个 θ_R ckpt、centers.json、rt jsons（LOO 带与参照值）；
  池/F_30/子样本构造同 E-W3。
- **带 = LOO 诚实系综带**（E-W3 探索读数的最小可辩护带）：种子 s 的
  带心 = 3 种子中位；带宽_s = 另外两个种子对带心的最大偏离（逐
  Tier-A 指标）。极端种子 c=0 不可行 → 起点投影：向中位种子模型
  混合 θ_s + t(θ_med − θ_s)，t ∈ 0.05 网格取最小可行 t；无可行 t →
  该种子记 capacity 0（构造性）。
- **目标（影响保留）**：mean F_30 正确类边际（m6_fm 量）。
- **构造 1（约束梯度）**：从（投影后）起点做投影梯度上升——候选 =
  当前 + lr·∇(F 边际)；接受 iff 可行（五 Tier-A 带）且边际改进；
  拒绝 lr 减半；接受 lr×1.1（上限初值）；stall>20 或 150 迭代停。
  lr 初值 1e-4。
- **构造 2（逐层贪婪回滚）**：对 c=0 可行的种子（44101），分组 =
  [BN 参数 | fc 权重 | fc 偏置 | conv1 | layer1–4 权重]，每组独立
  回滚 θ₀−θ_R 至各自最大可行 c（0.05 网格，其余组取当前最优），
  报告 ρ = 1 − ‖θ′−θ₀‖/‖θ_R−θ₀‖ 与 I1。
- **阳性对照（可证伪性）**：50 步**无约束**上升从 θ_R 出发须使 F
  边际提升 ≥ 0.5（logit 单位）——否则"无容量"不可与"优化器太弱"
  区分 → 判 UNDECIDED（优化器无效），不得据此宣称审计闭合。

## 2. 判定（冻结）

- **LOOPHOLE（UW 部分复活）**：任一构造达可行模型且 I1 ≥ 0.20。
- **AUDIT-CLOSED**：阳性对照通过，且全部构造停在 I1 < 0.20 →
  E-W3 的闭合从"插值族"升级为"回滚 + 局部优化"双面闭合。
- **UNDECIDED**：对照失败或投影无可行起点 ≥2 种子。
- 附带记录：utility 代价（可行点的 m1）、每迭代日志、逐层贪婪的
  组-可行曲线。

## 4. 执行期勘误（冒烟后、全量前，2026-09-23）

1. **对照发散**：固定 lr=1e-3 的无约束上升发散（冒烟实测 F 边际
   −304~−683）。修正：对照改用与主循环相同的自适应回溯（接受 iff
   F 边际改进；拒绝减半），评估改为仅 F 前向的轻量读数。对照语义
   不变（"优化器在无约束时确能提升 F 边际 ≥0.5"）。
2. **LOO 带起点不可行**：3 种子逐指标中位持有者不同，2/3 种子在
   任何混合 t 下不可行。修正：带改为**自含系综带** = 3 种子对带心
   的最大偏离（含自身；极端种子 dev=band 恰好通过 → 全部种子 c=0
   可行，投影机制废除）。带语义仍为"审计必须接受自己的诚实系综"，
   比 LOO 略宽（对攻击者略有利，AUDIT-CLOSED 结论方向保守）。
   判定逻辑不变。
3. **步长调度**：lr 初值 1e-4 时首步效应 Δfm ≈ lr·‖g‖² 低于接受
   阈值（第二次冒烟对照零接受）；固定 1e-3 无回溯则发散（第一次
   冒烟）。修正：lr 初值 1e-3 + 回溯减半（12 次）+ 增长上限 3e-3 +
   接受阈值 1e-7，对照与主循环同调度。判定逻辑不变。
4. **梯度符号错误**：初版 grad_delta 对 (−margin) 反传后按 +lr·grad
   步进 = 边际**下降**方向——阳性对照逐次抓住（固定 lr 冒烟发散至
   −300、自适应冒烟零接受，两形态皆由此解释）。修正为对 +margin 反
   传。对照机制按设计发挥作用；若无对照，约束循环会以"零接受"伪装
   成 AUDIT-CLOSED。

## 3. 预算与边界

~2h GPU（3 seeds × 150 迭代 × ~12s + 贪婪 ~25 min + 对照 ~10 min）；
无新训练。诚实边界：k=30 单点（床最自信处，漏洞若存在则最大）；
LOO 带 3 种子小样本；梯度法非全局最优（局部闭合声明）；
m5 固定弱对手；判定只覆盖 Tier-A（Tier-B 在 E-W3 已同闭）。
